# TorobGard — محدودیت‌های شناخته‌شده (Known Limitations)

> این سند محدودیت‌های واقعی پروژهٔ ترب‌گرد را بر اساس وضعیت فعلی کد
> (شاخهٔ `main`، commit `6b358e6` + اصلاحات Phase 1–11) فهرست می‌کند.

## ۱. وابستگی‌های خارجی پیکربندی‌نشده (`BLOCKED_EXTERNAL_DEPENDENCY`)

### ۱.۱ مسیریابی واقعی (Neshan Maps)
- **وضعیت**: `not_configured`
- **قرارداد اتصال**: `src/lib/torob/routing.ts` + `src/app/api/route/route.ts`
- **رفتار فعلی**: وقتی `NESHAN_API_KEY` تنظیم نشده باشد، `/api/route` از
  haversine (فاصلهٔ هوایی) استفاده می‌کند. هر segment با `is_estimated: true`
  و `has_real_routing: false` برچسب می‌خورد. هیچ فاصلهٔ رانندگی جعلی تولید نمی‌شود.
- **نمایش در UI**: تب «برنامهٔ خرید» یک badge نمایش می‌دهد:
  «فاصلهٔ هوایی (مسیریابی تنظیم‌نشده)».
- **روش پیکربندی**: کلید را از https://platform.neshan.org/ بگیر و در
  `.env` به‌صورت `NESHAN_API_KEY=...` قرار بده. `routing.ts` به‌طور خودکار
  از haversine به API واقعی سویچ می‌کند (هر segment با `is_estimated: false`).

### ۱.۲ ارتباط خودکار با فروشنده (تلفن/پیام‌رسان)
- **وضعیت**: `not_configured` (by design — رویکرد صادقانه)
- **قرارداد اتصال**: `src/lib/torob/tools.ts::prepareSellerInquiry` پیام
  فارسی آمادهٔ ارسال می‌سازد؛ هیچ provider تلفنی/پیام‌رسانی متصل نیست.
- **رفتار فعلی**: کاربر متن را کپی می‌کند و خودش از طریق تلفن یا پیام‌رسان
  ارسال می‌کند. `/api/confirm` نتیجهٔ تماس دستی کاربر را در حافظه (Map)
  ثبت می‌کند. **هیچ ادعای «تماس موفق» نشده** و وضعیت پیش‌فرض
  `unconfirmed` (یعنی «قیمت ثبت‌شده در تورب، تأییدنشده توسط فروشنده») است.
- **نمایش در UI**: پنل VerifyPanel در دستیار و ShopCard در فهرست فروشگاه‌ها
  هر دو یادآوری می‌کنند: «ارسال خودکار پیام به فروشنده پیکربندی‌نشده است
  (not_configured) — متن را کپی کن و خودت ارسال کن.»

### ۱.۳ LLM (z-ai SDK)
- **وضعیت**: `PASS` (پیکربندی‌شده در این محیط)
- **رفتار**: `/api/agent` از z-ai SDK استفاده می‌کند. اگر در دسترس نباشد
  (مثلاً 429 rate limit)، یک fallback تعیینی بر اساس `parseQuery` +
  `searchProducts` واقعی اجرا می‌شود. **fallback هرگز داده جعل نمی‌کند** —
  همیشه نتایج واقعی جست‌وجو را برمی‌گرداند.

## ۲. محدودیت‌های دیتاست (از `docs/DATA_AUDIT.md`)

| مورد | توضیح | نمایش در UI |
|---|---|---|
| نام فروشگاه‌ها | مصنوعی (synthetic) | `SyntheticNameBadge` («نمایشی») کنار هر نام + `DisclaimerList` در فوتر |
| قیمت‌ها | قدیمی (آخرین تغییر ۲۰۲۰ تا ۲۰۲۶) | «قیمت‌ها قیمت ثبت‌شده هستند و ممکن است تغییر کرده باشند.» |
| موجودی | در داده نیست | «موجودی کالا تأیید نشده است — قبل از مراجعه تماس بگیرید.» |
| ~۴٫۵٪ بدون قیمت | `price_toman = null` | badge «قیمت نامشخص» در کارت‌ها و پیشنهادها |
| برند ۷۴٫۵٪ مفقود | `brand = null` | «نامشخص» به‌جای نام برند |
| فاصله‌ها | haversine (هوایی)، نه رانندگی | badge در تب برنامهٔ خرید + متن توضیحی |
| شماره تماس | از دیتاست (نمایشی) | `tel:` link فقط اگر در `contacts` باشد؛ هیچ شمارهٔ جعلی ساخته نمی‌شود |

## ۳. محدودیت‌های پارسر (مستندشده)

| ورودی | رفتار | علت |
|---|---|---|
| `یک میلیون` (عدد نوشتاری بدون واحد) | `parseBudgetToman → null` | پارسر فقط اعداد لاتین/فارسی + واحد می‌گیرد |
| `زیر یک میلیون` | `parseQuery → maxBudget = 1000000` ✓ | `WORD_NUM` map «یک» را پشتیبانی می‌کند |
| `دو میلیون` | `parseBudgetToman → null` | «دو» قبل از واحد فقط در `parseQuery` کار می‌کند، نه `parseBudgetToman` |
| `11` (یازده) و بالاتر | پشتیبانی نمی‌شود | `WORD_NUM` فقط ۱ تا ۱۰ را دارد |
| `بلوتوثی` | به‌عنوان term جست‌وجو می‌ماند، نه connectivity | برای جلوگیری از حذف هدفون‌های بلوتوثی که «بی سیم» در عنوانشان نیست |

## ۴. محدودیت‌های پایداری

| مورد | توضیح |
|---|---|
| تأیید فروشنده در حافظه | `recordSellerConfirmation` در یک `Map` در حافظه نگه‌داری می‌شود — پس از restart سرور پاک می‌شود. عمدی: هیچ ادعای تأیید پایدار بدون لایهٔ persistence واقعی نشده. |
| سبد خرید در localStorage | `zustand persist` به `localStorage` متصل است. در tab/مرورگر دیگر به‌اشتراک گذاشته نمی‌شود. |
| نرخ درخواست LLM | هیچ rate limiter روی `/api/agent` نیست. اگر API public شود، اضافه شود. |

## ۵. محدودیت‌های فنی شناخته‌شده

| مورد | وضعیت | اقدام |
|---|---|---|
| `typescript.ignoreBuildErrors: true` در `next.config.ts` | روشن | باید بعد از رفع خطاهای TS5097 در `scripts/verify-tools.ts` (import با پسوند `.ts`) خاموش شود |
| `reactStrictMode: false` | خاموش | می‌تواند روشن شود ولی ممکن است double-render در dev باعث هشدار شود |

| `data/raw/starcoach-dataset-v16-cap300-csv.zip` (58MB) در git | tracked | بهتر است به release asset منتقل شود (هم‌اکنون روی repo پوش نمی‌دهیم) |

- تمام دکمه‌ها `<button>` با `aria-label` فارسی هستند.
- `dir="rtl"` و `lang="fa"` در `<html>`.

- هیچ `dangerouslySetInnerHTML` در کد ما نیست (فقط در shadcn `chart.tsx` که static CSS است).
- منوی TopNav با کیبورد پیمایش می‌شود.
